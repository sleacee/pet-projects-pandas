# Аналитические проекты на Python

Репозиторий с учебными и pet-проектами по анализу данных. В проектах рассматриваются задачи классификации, прогнозирования, исследования данных, анализа продуктовых метрик и подготовки аналитической отчётности.

## Структура репозитория

Каждый проект представлен отдельным Jupyter Notebook с кодом, промежуточными результатами, визуализациями и выводами.

## Проекты

### 1. [Классификация продуктов питания](Food%20Composition%20Data%20USDA.ipynb)

**Объект исследования:** датасет USDA из 8 790 записей с информацией о пищевой ценности продуктов и категориальным признаком `CLASS`.

**Цель:** подготовить данные и исследовать возможность классификации продуктов с помощью алгоритма K-ближайших соседей (KNN).

**Что сделано:**
- Проведён первичный статистический анализ признаков.
- Исследованы пропущенные значения и распределение классов.
- Выполнена подготовка данных для обучения модели.
- Применены StandardScaler и MinMaxScaler для нормализации признаков.
- Обучена модель KNN и сравнены результаты при разных способах масштабирования.

**Результат:** точность модели составила около 85,3% без нормализации и после StandardScaler, а после MinMaxScaler — около 83,7%. Проведено сравнение влияния способов масштабирования признаков на качество классификации.

### 2. [Анализ цен на бриллианты](алмазы.ipynb)

**Объект исследования:** датасет из 53 940 записей с информацией о стоимости бриллиантов, массе, огранке, цвете, чистоте и геометрических характеристиках камней.

**Цель:** изучить характеристики бриллиантов и построить модель для прогнозирования их стоимости.

**Что сделано:**
- Проведён первичный статистический анализ количественных и категориальных признаков.
- Проверены пропущенные значения и исследованы распределения признаков.
- Выполнена визуализация характеристик бриллиантов.
- Подготовлены данные для построения модели.
- Обучена модель линейной регрессии и рассчитаны метрики качества прогнозирования.

**Результат:** на тестовой выборке получено значение \(R^2 \approx 0{,}906\). Модель объясняет значительную часть вариации целевой переменной. Результаты прогнозирования сопоставлены с фактическими значениями.

### 3. [Анализ данных о пингвинах](пингвины.ipynb)

**Объект исследования:** датасет из 344 наблюдений о пингвинах трёх видов с информацией об их физических характеристиках, острове обитания и поле.

**Цель:** исследовать структуру данных и применить основные методы предобработки, визуализации и уменьшения размерности.

**Что сделано:**
- Проведён первичный статистический анализ признаков.
- Проверены пропущенные значения и выполнена их обработка.
- Построены графики распределения количественных и категориальных признаков.
- Выполнена нормализация числовых данных.
- Проведено кодирование категориальных признаков.
- Применён метод главных компонент (PCA) для проекции данных в двумерное пространство.

**Результат:** подготовлены данные для дальнейшего анализа и построена двумерная проекция наблюдений с помощью PCA. Проект демонстрирует основные этапы подготовки и визуального исследования данных.

### 4. [Продуктовая воронка](Продуктовая воронка.ipynb)

**Объект исследования:** данные о пользовательской воронке приложения аренды автомобилей за 8 недель.

**Цель:** оценить конверсию между этапами воронки, проследить её динамику и выявить этапы с наибольшими потерями пользователей.

**Что сделано:**
- Рассчитаны конверсии между этапами воронки.
- Проанализирована динамика показателей по неделям.
- Построены графики изменения конверсий.
- Исследованы изменения общей конверсии от установки до первой поездки.

**Результат:** общая конверсия от установки до первой поездки составила около 24,4%. На 7-й неделе конверсия из регистрации в открытие поиска снизилась с 70,8% до 49,4% относительно предыдущей недели. Этот этап представляет интерес для дальнейшего исследования причин снижения конверсии.

### 5. [Пролонгация договоров](Пролонгация договоров.ipynb)

**Объект исследования:** финансовые данные по клиентским проектам и информация о пролонгациях договоров за 2023 год.

**Цель:** оценить показатели пролонгации договоров и подготовить аналитическую отчётность по аккаунт-менеджерам и отделу в целом.

**Что сделано:**
- Рассчитаны коэффициенты пролонгации для разных периодов после завершения проекта.
- Выполнена агрегация показателей по менеджерам и месяцам.
- Рассчитаны годовые показатели сотрудников и отдела.
- Подготовлены отчётные таблицы для дальнейшего анализа.

**Результат:** сформированы отчёты, позволяющие сравнивать показатели пролонгации договоров и анализировать их динамику на уровне сотрудников и отдела.

## Инструменты

- **Python** — анализ и обработка данных.
- **pandas** — работа с таблицами, фильтрация, группировки и расчёт показателей.
- **NumPy** — численные вычисления.
- **Matplotlib** — визуализация данных.
- **SciPy** — статистические методы и проверка гипотез.
- **Scikit-learn** — построение и оценка моделей машинного обучения.
